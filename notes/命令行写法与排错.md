# 命令行写法与排错速查（打靶场专用）

> **为什么需要这份**：从聊天窗口 / 网页复制命令时，特殊字符会被悄悄改动（加 `@url:` 前缀、`%20` 变成真空格），命令就莫名失败。**学会自己写 = 不再依赖复制**。

---

## 一 最重要的规矩：命令写进文件，别从聊天复制

复制会改字符，这是你这两天踩得最多的坑。正确姿势：

```bash
nano ~/xx/CS/scripts/我的测试.sh      # 或用 VS Code 新建文件
#  把命令写进去，Ctrl+O 保存、Ctrl+X 退出
bash ~/xx/CS/scripts/我的测试.sh      # 运行
```

脚本文件里的字符是**精确的**，不会被任何界面改动。

---

## 二 URL 里的特殊字符必须编码

URL 里这些字符有特殊含义（空格非法、`#` 是锚点、`&` 是参数分隔），**必须转成 `%xx`**：

| 字符 | 编码 | 例 |
|---|---|---|
| 空格 | `%20` | `order by 3` → `order%20by%203` |
| 单引号 `'` | `%27` | `1'` → `1%27` |
| 双引号 `"` | `%22` | |
| `#` | `%23` | |
| `&` | `%26` | |

---

## 三 更省事：让 curl 自己编码（推荐）

```bash
curl -s -G "http://127.0.0.1:8083/Less-1/" --data-urlencode "id=-1' union select 1,2,database()#"
```

- `-G`：把后面的 `--data-urlencode` 拼成 GET 查询串
- `--data-urlencode`：**自动编码** payload —— 你直接写真实的 `'` 和空格，不用手敲 `%27/%20`
- ⚠️ **SQL 注释符用 `#`，别用 `--+`**：`+` 会被编成 `%2b`（真加号），而 MySQL 的 `--` 注释后面**必须跟空格**，`--+` 不生效 → 整个 payload 失效。

---

## 四 先 dry-run，再看实际请求

写完别急着跑，先看 curl **到底发出去了什么**：

```bash
curl -v -G "http://127.0.0.1:8083/Less-1/" --data-urlencode "id=1' order by 4#" -o /dev/null 2>&1 | grep "^> GET"
# > GET /Less-1/?id=1%27+order+by+4%23 HTTP/1.1
```

看到 `> GET` 那行，就知道编码对不对 —— **这一步能省掉 90% 的"为什么不工作"**。

## 五 curl 错误码速查

| 错误码 | 含义 | 常见原因 |
|---|---|---|
| `(3) URL rejected` | URL 有非法字符 | **没编码的空格**（最常见） |
| `(6) Couldn't resolve host` | DNS 失败 | 域名/主机名写错 |
| `(7) Failed to connect` | 连不上 | 服务没起 / 端口错 |
| `(52) Empty reply` | 服务器没回数据 | 后端服务异常 |

## 六 脚本模板（直接套）

```bash
#!/usr/bin/env bash
set -u
BASE=http://127.0.0.1:8081

# 需要登录态的靶场：先拿 session
COOKIE=$(mktemp); trap 'rm -f "$COOKIE"' EXIT
TOK=$(curl -s -c "$COOKIE" "$BASE/login.php" | grep -oE "user_token' value='[a-f0-9]+'" | head -1 | cut -d"'" -f3)
curl -s -b "$COOKIE" -c "$COOKIE" -b "security=low" \
  -d "username=admin&password=password&Login=Login&user_token=$TOK" \
  -o /dev/null "$BASE/login.php"

# 现在带着登录态发请求
curl -s -b "$COOKIE" -b "security=low" "$BASE/vulnerabilities/xss_r/?name=%3Cscript%3Ealert(1)%3C/script%3E" \
  | grep -oE "<pre>Hello.*</pre>"
```

---

## 七 三条心法

1. **写文件，别复制** —— 复制必改字符。
2. **让工具编码，别手写 `%xx`** —— `curl --data-urlencode` 就是干这个的。
3. **看实际请求（`curl -v`），别猜** —— 猜是最浪费时间的。
