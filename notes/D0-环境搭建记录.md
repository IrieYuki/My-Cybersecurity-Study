## 五、踩坑记录（都是今晚真遇到的）

1. **Kali 镜像必须下 arm64。** kali.org 默认页面给的是 amd64；M5 上跑 amd64 只能纯模拟，Metasploit / hashcat 会慢到不可用。
2. **官方源慢到离谱，换清华镜像。** `cdimage.kali.org` 实测约 130 KB/s（要下 9 小时）；`mirrors.tuna.tsinghua.edu.cn/kali-images/current/` 实测 **71 MB/s**，3.7 GB 用了 48 秒。下完务必 `shasum -a 256 -c` 对官方 SHA256SUMS。
3. **单线程慢的站，用 aria2c 多线程。** Burp 官方 CDN 单线程只有 200 KB/s，`aria2c -x8 -s8` 实测 **11 MB/s**（快 50 倍）。brew 自己的下载不支持断点续传，所以先用 aria2 下好、再按 brew 缓存的命名规则塞进 `~/Library/Caches/Homebrew/downloads/` 可以省掉重复下载。
4. **Wireshark 的安装需要管理员密码**（要装 ChmodBPF 和 PATH 两个 pkg），但装完就一劳永逸：`/dev/bpf0` 归 `access_bpf` 组，之后**普通用户就能抓包**，不需要 sudo。验证：`dumpcap -i lo0 -a duration:3 -w /tmp/x.pcapng`。
5. **brew 装的 docker-compose 不会自动注册成 docker 插件**（会报 `unknown command: docker compose`）。手动软链：
   `ln -sf "$(brew --prefix)/bin/docker-compose" ~/.docker/cli-plugins/docker-compose`（buildx 同理）。
6. **Docker Hub 在国内会 TLS 握手超时。** 解决：给 colima 里的 docker 写镜像加速 —— `labs/docker-daemon.json` → 拷进 VM 的 `/etc/docker/daemon.json` → 重启 docker。用的是 `docker.m.daocloud.io` 和 `docker.1ms.run`。
7. **colima 的 VM 有时 DNS 不通**（报 `lookup ... on [::1]:53: connection refused`）。解决：`colima stop && colima start --dns 223.5.5.5 --dns 119.29.29.29 --dns 8.8.8.8`。
8. **不要用 Docker Desktop 做 7 天冲刺的靶场环境**：要管理员授权、要登录账号、要吃 2 GB 磁盘。colima 全程免密码、终端里一行命令搞定，PHP 靶场性能完全够。
9. **本地端口测试要绕过代理。** 如果终端里 export 了 `ALL_PROXY=http://127.0.0.1:7897`，`curl http://127.0.0.1:8081` 会被送去 Clash 而返回 **502**，看起来像靶场挂了。正确姿势：`curl --noproxy '*' http://127.0.0.1:8081`。
10. **`docker pull` 失败是常态，要重试。** 走镜像站拉 5 个靶场镜像，中途出现过至少 3 次 TLS 握手超时；写成 `until docker pull ...; do sleep 8; done` 循环重试即可。带 `| tail -3` 的 `if docker pull ...` 判断恒为真（管道退出码是 tail 的），别用它当重试条件。
